# 📊 Retail Sales Analysis Dashboard — Excel & Power BI

## Project Overview

This project analyzes a retail sales dataset to identify key business trends and provide actionable insights into sales performance, product performance, regional performance, customer segments, and shipping efficiency.

The project uses **Microsoft Excel** for data cleaning and exploratory analysis and **Microsoft Power BI** for interactive data visualization and dashboard development.

---

## Project Objectives

The main objectives of this project are:

- Analyze overall sales performance.
- Identify sales trends over time.
- Determine the highest-performing product categories and sub-categories.
- Identify top-performing products.
- Compare sales performance across different regions.
- Analyze customer segments.
- Evaluate shipping modes and delivery performance.
- Build an interactive dashboard to support data-driven decision-making.

##  Dataset

The project uses a retail sales transaction dataset containing information about:

- Orders
- Customers
- Products
- Categories
- Sub-Categories
- Sales
- Regions
- Customer Segments
- Shipping Modes
- Order Dates
- Ship Dates

The dataset contains approximately **9,800+ sales transactions**.
